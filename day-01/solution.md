# Прыгун (The Jumper)

## Цель игрока
Собрать 3 кристалла, разбросанные по уровню, и коснуться двери-выхода.

## Управление
- **A / D** (или стрелки) — движение влево / вправо.
- **Space / W** — прыжок.

## Враг (состояния)

- **patrol:**
  - *Вход:* Старт игры / игрок вышел из радиуса обнаружения.
  - *Тик:* Движение по оси между двумя точками. При достижении точки — инверсия вектора скорости.
  - *Выход:* Дистанция до игрока <= `detect_radius`.
- **chase:**
  - *Вход:* Переход из `patrol` (сработал `detect_radius`).
  - *Тик:* Расчет вектора к игроку, нормализация, умножение на `chase_speed`. Обновление направления спрайта.
  - *Выход:* Дистанция до игрока <= `attack_radius` (переход в `attack`) ИЛИ дистанция > `lose_radius` (переход в `patrol`).
- **attack:**
  - *Вход:* Переход из `chase` (сработал `attack_radius`).
  - *Тик:* Рывок в сторону текущего направления с `attack_speed`. Инкремент таймера `attack_duration`.
  - *Выход:* `attack_duration` >= лимит ИЛИ коллизия со стеной. Переход в `patrol`.

## Победа / поражение
- **Победа:** Коснуться хитбоксом двери-выхода, собрав 3 кристалла.
- **Поражение:** Любое пересечение хитбокса игрока с хитбоксом врага. Рестарт уровня с начала.

## Что можно добавить позже (макс. 3)
1. Добавить второй тип врага с другой траекторией движения.
2. Сделать несколько экранов-уровней с переходом между ними.
3. Добавить звуковые эффекты (прыжок, сбор кристалла, смерть).
